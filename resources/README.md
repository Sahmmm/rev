# Ressources pedagogiques

Ce dossier regroupe les documents utilises pour construire les contenus de
revision en deep learning.

## Dossiers

- `courses/` : supports de cours, chapitres, slides et polycopies.
- `exams/` : annales, sujets de rattrapage, corrections et exercices type examen.
- `tp/` : enonces, notebooks, scripts et corrections de travaux pratiques.
- `personal-notes/` : fiches personnelles, resumes et notes de revision.
- `processed/` : contenus transformes ou structures pour alimenter l'application
  plus tard, par exemple jeux de flashcards ou questions a reponse ecrite.

Les fichiers originaux doivent rester dans leur dossier source. Les versions
nettoyees ou structurees pourront etre placees dans `processed/`.
